# It's just a game.

لعبة هروب بالبكسل مستوحاة من الصديقات والكلية.

## آخر التعديلات
- توحيد الواجهة والتعليمات والرسائل بالعربية، مع إبقاء اسم اللعبة وعبارة الوحش الإنجليزية.
- دعم زر E مع الكيبورد العربي وتصحيح نطاق التفاعل وتركيز قفل المصعد.
- تحريك كل البنات في الغرفة الأولى أثناء المطاردة، مع تجنّب الأثاث وإعادة أماكنهن عند إعادة اللعب.
- دعم الأرقام العربية والإنجليزية في قفل المصعد.

## التشغيل
شغّلي المجلد بخادم محلي مثل Live Server في VS Code، ثم افتحي index.html من الخادم.
لا يحتاج المشروع إلى مفاتيح API أو خدمات خارجية. مكتبة Three.js مرفقة بترخيصها.

## التعديل
- main.js: السيناريو وحركة الغرفة الأولى والتحكم.
- engine.js: قواعد اللعبة والمسارات والهروب والتفاعل مع المصاعد.
- elevator-level.js: لغز المصاعد الثلاثة.
- final-escape.js: الممر وقفل المصعد والخروج.
- campus.js: واجهة الجامعة والنهار والليل.
- style.css: تصميم الواجهة.
- index.html: نصوص الواجهة وعناصرها.

## الاختبارات
مع تثبيت Node.js، شغّلي: npm run check

## الرفع
فكّي الضغط وارفعي محتويات المجلد إلى GitHub، ثم اربطي المستودع في Vercel.
ملف vercel.json يحدد إعدادات النشر. ملف index.html موجود بجذر المشروع.

الجزء الثاني والطابق الثالث لم يُنفّذا في هذه النسخة بعد.
