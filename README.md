# It's just a game. — نسخة Vercel المصححة

كل ملفات هذه النسخة في مجلد واحد عمدًا. تم تعديل مسارات الصور ومكتبة الرسم لتعمل من المجلد نفسه، حتى لو رفعتي الملفات بدون مجلدات فرعية.

## استبدال النسخة القديمة
1. فكي ضغط ZIP.
2. افتحي المستودع المرتبط بمشروع Vercel.
3. استبدلي ملفات اللعبة القديمة بمحتويات ZIP كاملة، بما فيها الصور وthree.module.js وthree.core.js وvercel.json. ارفعي الملفات نفسها إلى جذر المستودع، وليس ملف ZIP فقط.
4. احفظي التغيير في GitHub. إذا المشروع مربوط، يبدأ النشر تلقائيًا؛ وإلا اختاري Redeploy.
5. افتحي الرابط بعد انتهاء النشر وحدّثيه بـ Ctrl+Shift+R.

إعدادات Vercel مضمنة في vercel.json. Root Directory يكون جذر المستودع، Framework يكون Other، بدون أمر Build أو Install، وOutput Directory هو نقطة واحدة: .
إذا كان Root Directory في مشروع Vercel مضبوطًا على dist غيّريه إلى جذر المستودع لهذه النسخة.

## تشغيل محلي
بعد تثبيت Node.js شغلي START_GAME.bat أو npm start، ثم افتحي http://localhost:8080. لا يلزم npm install.

## التعديل
- main.js: المقر والسيناريو والكاميرا والتحول والمطاردة الأولى.
- index.html وstyle.css: الواجهة والأزرار والتنسيق.
- pixel-characters.js: الشخصيات وحركة الأرجل.
- elevator-level.js: بهو الطابق الثاني والمصاعد الثلاثة.
- final-escape.js: ممر الطابق الأول وصندوق الشفرة والعدّاد والخروج والنهاية.
- engine.js: قواعد الحركة والاصطدام والألغاز.
- ملفات PNG: صور الشخصيات والخلفيات. احتفظي بأسمائها إن استبدلتِ الصور.
- npm run check: اختبارات قواعد اللعبة.

هذه النسخة تشمل كل المراحل والشخصيات والخلفيات. تعديلها لا يغيّر أي رابط منشور حتى تعيدي النشر. ترخيص Three.js محفوظ في LICENSE.
