# It's just a game. — الكود القابل للتعديل

نسخة كاملة من كود اللعبة المنشورة، تشمل الشخصيات والخلفيات والوحش والمراحل والألغاز والاختبارات. لا تحتاج مفاتيح API أو قاعدة بيانات. بعد تثبيت Node.js تعمل محليًا دون إنترنت أو npm install.

## التشغيل على ويندوز
1. فكي ضغط ملف ZIP بالكامل.
2. افتحي مجلد its-just-a-game في VS Code.
3. شغلي START_GAME.bat، أو اكتبي `npm start` في التيرمنال داخل المجلد.
4. افتحي http://localhost:8080 في المتصفح واتركي التيرمنال مفتوحًا.
5. لإيقاف السيرفر اضغطي Ctrl+C في التيرمنال.

إذا لم يكن Node.js مثبتًا، ثبتيه أولًا. يمكن أيضًا تشغيل مجلد dist بواسطة Live Server في VS Code. لا تفتحي index.html مباشرة عبر file:// لأن ملفات JavaScript تستخدم modules وتحتاج سيرفر HTTP.

## أمثلة سريعة
- خلفية البداية: start-screen.png داخل dist/assets.
- خلفية الطابق الثاني: second-floor-hall.png.
- ممر الطابق الأول: first-floor-corridor.png.
- البهو الأخير: elevator-lobby.png.
- خلفية الفوز: college-outside.png.
- اسم اللعبة: ابحثي عن It's just a game. في index.html. الاسم داخل صورة البداية جزء من الصورة ويحتاج تعديل الصورة نفسها.
- مهلة الوحش: ابحثي عن 20 في tickCorridor داخل engine.js، ثم حدّثي العداد والنصوص المرتبطة في final-escape.js معًا.
- الشفرة عشوائية من ٤ أرقام في FinalEscape.start داخل final-escape.js. لتثبيتها استبدلي تعبير توليد الأرقام بـ newCorridor('6382').
- أماكن لوحات الأرقام: مصفوفة markers أعلى final-escape.js. الإحداثيات نسب من 0 إلى 1 من عرض وارتفاع المشهد.
- سرعة الوحش في الممر والبهو الأخير: العامل .10 في حركة this.m داخل final-escape.js.

احفظي الملفات ثم حدثي المتصفح لرؤية التعديل. هذه نسخة مستقلة: تعديل ملفات جهازك لا يحدث رابط اللعبة المنشور تلقائيًا، بل يحتاج إعادة نشر.

## تسلسل اللعبة الحالي
البداية ← اختيار واحدة من ست شخصيات ← سباق سينمائي ← تحول صاحبة الشعر الأحمر ← جمع ثلاثة مفاتيح والهروب من المقر ← بهو الطابق الثاني ولغز المصاعد ← النزول للأول ← ممر فيه أربع لوحات أرقام وقفل مصعد ← الوحش يصل بعد ٢٠ ثانية من وقت اللعب ← فتح القفل ← البهو الأخير ← الخروج يسارًا ← الفوز خارج الكلية.

اللعبة فردية، والخمس صديقات الأخريات يتحركن بالذكاء الاصطناعي. السباق مقطع سينمائي. المقر ثلاثي الأبعاد باستخدام Three.js والشخصيات صور بكسل ثنائية الأبعاد. البهو والممر يستخدمان Canvas 2D. الصور PNG وليست ملفات رسم بطبقات قابلة للتحرير.

## التحكم
WASD أو الأسهم للحركة، Shift للركض، Space للاندفاع، E للتفاعل، P أو Escape للإيقاف. يمكن الضغط على الأرض للحركة أو استخدام أزرار اللمس. القائمة تشمل اختصارات تجربة المراحل.

## التحقق
شغلي `npm run check`. تختبر القواعد: الاصطدام والمسارات والمفاتيح والصحة، الشخصيات الست، اختيار المصعد والنزول، حركة الأرجل، ملاحقة الوحش، مهلة العشرين ثانية، التحقق من الشفرة والخروج من اليسار فقط.
